> `c6733ae1276880507ca0c5b053ae18fb0df090d6`). That is 106 days 17 h apart (~15 weeks) and **103 patch

## The big story

2.1.169 → 2.1.197 was three weeks of consolidation. **2.1.197 → 2.1.300 is the largest structural step
since 2.1.32 → 2.1.169.** The surface roughly doubled on every axis that can be counted. Five changes
account for most of it:

1. **The binary was re-platformed, and plugins became a runtime.** The 18 MB CommonJS IIFE became a
   24,477-byte ESM loader plus 2,395 lazily loaded chunks (1,398 `import()` sites into 708 chunks). Docs and
   skills moved into 252 zstd/text assets. On top of that new packaging sits a first-party **function-hooks
   engine**: one shared `Worker` thread (`ahn()` `:508910`) runs every plugin's TypeScript hooks module as a
   `vm.SourceTextModule` in a hardened realm with no string codegen and no wasm. Plugins can draw UI
   ("**mods**": `Pane` / `AbovePrompt`, 15 render sites), and **11 built-in features ship as hook plugins**
   on that engine, gated by `tengu_plugin_hooks_modules` (default **true**). See
   [architecture](../versions/2.1.300/architecture.md).

2. **The Claude 5.5 generation landed, and Opus became the default for far more people.** Six new catalog
   entries: Opus 5, **Opus 5.5**, **Sonnet 5.5**, **Haiku 5.5**, **Fable 5.1**, **Mythos 5.1**. Every alias
   default moved to the newest model in its family (`:21186–21227`, verified). `isOpusDefaultSubscriber`
   (`qVn` `:126308`) now covers Pro, Team and every Enterprise plan, and Bedrock/Vertex also default to Opus.
   Pricing moved into the catalog. A **signed, remotely servable model catalog** can override the compiled
   defaults, behind `tengu_delegated_quail` (default `{mode:"off"}`, `:792214–792217`). See
   [model-references](../versions/2.1.300/model-references.md).

3. **Your machine became a remote tool host.** A new `violin_*` family (28 flags, all NEW) gates this
   computer *serving* its tools, hooks and settings to cloud sessions. It is backed by the first genuine
   **device credential** in the product: a per-account ECDSA P-256 key in `~/.claude/.device-keys.json`,
   registered at `/api/organizations/:orgUUID/cowork/remote_devices`, used to sign session-bind
   attestations, and **preserved across logout** (`:958978`, `:959050–959060`). The same push brought
   **self-hosted runners** (`/v1/code/runners/self-hosted/*`, 9 `self_hosted_runner_*` tools), the CCR
   worker v2 API, and a raw `remoteControlMachineId` UUID sent on bridge registration.

4. **Bash safety went fully deterministic, and the model-based checks moved to auto-mode.** The Haiku-class
   **LLM prefix classifier** has been the centrepiece of every security doc since 2.1.32. It is **gone**:
   `command_injection_detected` occurs 7 times in 2.1.197 `cli.min.js` and 0 in 2.1.300. Its place is taken
   by a tree-sitter AST analyser (85 → 149 "too-complex" sites), a typed circuit-breaker registry (`Idn`
   `:25410`) and a rebuilt **auto-mode classifier**: graded severity, consent bars, 72 SOFT rules, **Sonnet 5**
   as the default classifier model, and a NEW **server-side "arbiter"** (`cE()` `:431829`, beta
   `dangerous-tool-use-2026-09-03`).

5. **Compliance and enterprise plumbing.** A NEW **HIPAA-safe telemetry mode** rewrites every 1P/Datadog/OTel
   row against strict validators and turns free strings into `"hipaa_redacted"`. A declarative 36-key org-policy
   registry now drives command gating through `policyGate`. Settings files can no longer inject ~200 sensitive
   env keys. And a new **Claude Platform on Google Cloud** provider plane (`anthropicGoogleCloud`,
   `https://claude.googleapis.com`) sits alongside the existing ones.

The flag-default shift is the change that touches every user. **232 of 704 flags default to literal `true`**,
against 30 of 251 in 2.1.197, and **199 of the 519 new flags ship default-on**. Most new GrowthBook names are
remote kill switches for code that already runs, not opt-in experiments.

## Packaging & runtime (the structural headline)

- **ESM, code-split, Bun 1.4.3.** 2,651 embedded files in the ELF `.bun` section: 2,401 application JS
  modules (2,395 `chunk-<hash>.js` + `cli` + `hooks-worker.js` + two addon wrappers + 2 `.mjs`), 139 `.zst`,
  79 `.md`, 25 `.txt`, 2 `.node`, 2 fonts, 3 vendored browser libraries. *Correction carried from the
  architecture doc:* `ANALYSIS_CONTEXT.md` said "2,399 `chunk-*.js`". The manifest has **2,395**. The 2,401 and
  2,651 totals are correct.
- **Start-up by path.** `claude --version` links 7 modules (35,804 B). The interactive `main` path (module 777)
  has a 686-module static closure, about 37% of module-body bytes. Each fast path (daemon worker, PTY host,
  bg spare, remote-control, `agents`, **NEW** `self-hosted-runner`, `plugin test`, `--eval-mock-server`,
  `--gh-standin`) loads only its own subgraph (`:528–1325`).
- **Bun 1.4.3 is baked in:** `bun_version:"1.4.3"` in the error-report payload (`:350265`) and a NEW
  `FKn()` = `Gw("1.4.3","1.4.0")` gate that enables stall-detecting streamed uploads (`:136711`). On this
  binary the gate is always true. **NEW** `Bun.unsafe.setJITPolicy?.(1)` runs 10 s after start
  (`:574–577`). What policy `1` means is **not established** from this source.
- **Native addons:** `image-processor.node` **REMOVED**, replaced by `Bun.Image` (`Me()` `:363474`).
  `clipboard-napi.node` is **NEW** (a Linux clipboard fallback after `wl-copy`/`xclip`/`xsel`).
  `audio-capture.node` is carried.
- **Assets:** skill corpora (`claude-api` 103 files, `design-sync`, `dataviz`, `run`/`verify`, …), loop
  preambles, ultraplan templates and the auto-mode rules template moved out of JS. They are read through a
  zstd-sniffing reader (`Bun.zstdDecompressSync` `:372901`; `zstdDecompress` occurs 0 times in 2.1.197).
  **This move is why the 2.1.300 env/API/model counts run over JS + 243 decompressed text assets.**
- **VM hardening tightened:** 2.1.197's `hardenVMIntrinsics` comment said eval was kept for REPLTool
  (`codeGeneration:{strings:true}`). In 2.1.300 every hardened realm (hooks, workflows, the error formatter)
  passes `strings:false, wasm:false`, and the REPL tool has no factory site.

## Feature flags (251 → 704, +453†)

`k/vn/vr/MG/rb/V9e` set gives 692. Narrow against narrow is 243 → 692 (+449); full against full is
251 → 704 (+453). **For flags the method barely moves the delta; the growth is real.** A further
32 names reach the accessors only through wrappers. They are counted separately (736) because 2.1.197 was
never counted that way.

  (`:142869`, first read cached in `pinnedFeatureValues`) and "own-off-first" `V9e()`. Module 152 injects
  `k`/`vn`/`vr` into 17 reader registries (`:142994–143022`).
- **Largest new families:** `bridge_*` (26 new), `ccr_*` (25), `violin_*` (28, served-tool host),
  `cobalt_plinth_*` (19, artifacts), `mcp_*` (18, transport hardening), `harbor_kite_*` (6, cross-session
  peer messaging), plus built-in mod switches `tengu_agents_md_mod` (default **true**) / `mermaid_mod` /
  `tips_mod` / `quiet_ember`.
- **Default flips (no kept boolean went `true`→`false`):**
  - `tengu_lapis_anchor` `"off"` → **`"padded-countdown"`**: the `<total_tokens>` reminder is on by default
    (`:491617`).
  - `tengu_harbor_willow` and `tengu_moss_anchor` `false` → **`true`**: sessions default into **auto mode**

## Security model (the classifier layer was replaced, not tuned)

Unlike 2.1.169 → 2.1.197, where the security *content* was nearly byte-identical, this cycle rewrote it:

- **REMOVED: LLM bash prefix classifier.** `command_injection_detected`, `tengu_bash_prefix`,
  `bash_extract_prefix` and the "Code Code" policy header occur 0 times in the JS, the assets and the raw
  strings. The prefix hook slot in `_Be` survives, but both callers pass `void 0` (`:583787`, `:711326`).
  Allow-rule suggestions come from a deterministic command-spec walker (`YZ()` `:545130`).
- **NEW deterministic layers:** AST "too-complex" sites 85 → **149**. `safetyCheck` sites 20 → **196**. A
  9-entry circuit-breaker registry (`Idn`). The `&` background operator now asks. A per-spawn
  `bashCommandClamp`. `--restricted` mode and `permissions.blockReadsOutsideWorkingDirectories` (0 occurrences
  in 2.1.197).
- **Auto-mode classifier rebuilt.**
  - **Rules:** they now ship as a bundled asset (`permissions_external-*.txt`). SOFT-BLOCK 55 → **72**
    (+19, −2: "Git Push to Default Branch" and "Unverified Destination" are gone). ALLOW 16 → 17.
  - **Consent:** a consent-bar framework (`[named+specifics]`, Path A/B).
  - **Scoring:** graded `<severity>` scoring with per-model thresholds, and a NEW `<category>` output tag.
  - **Classifier model:** **Sonnet 5** by default (`cL()` `:125104`), with the main model as fallback.
  - **Beta header:** `auto-mode-classifier-2026-07-16`.
  - **Source inconsistency:** the prompt names a "Synthetic Input Self Drive" rule that is **not** in the
    shipped SOFT list.
- **NEW server-side "arbiter"** (`cE()` `:431829`). It is `arbiter` on firstParty and
  `arbiterWithLocalFallback` on 3P planes, and it reads `safeguard_results` from the response. *How the local
  and server verdicts combine was not fully traced.*
- **REMOVED: `tengu_velvet_mallet`/`_hammer`** (the per-model read-before-write bypass flags). Skip decisions
  now come from a model allow-set plus the permission layer.
- **Sandbox:** credentials gain a **`mask`** mode (sentinel substitution, JWT claim masking, SigV4/AWS
  pairs). Windows adds a dedicated `srt-sandbox` user and WFP egress-fence verification.
- **Credential storage:** NEW `windows-credman` and `*-with-plaintext-fallback` backends.
  `.credentials.json` is opened with `O_NOFOLLOW`.
- **Secret scanner:** 7 low + 40 high rules → 12 + 52. The sensitive-key regex now tolerates invisible
  characters.
- **NEW provenance frames** (`[Workflow harness — …]`, `[Subagent hand-back]`) with an indentation
  anti-forgery rule. NEW built-in **Claude Test** plugin (v0.4.28) with its own browser egress fence and
  secret-typing vetting.
- **Unchanged:** the destructive-command warning regexes (16 unix + 15 PowerShell) and the
  `/security-review` prompt, which is **byte-identical** (diffed).

See [security-model](../versions/2.1.300/security-model.md).

## Bottom line

2.1.300 is a **re-platforming release**, the first since Node SEA → Bun. Its shape:

- The binary is now code-split ESM.
- Plugins run in a sandboxed worker and can draw UI, and Anthropic's own features ship on that plugin engine.
- The Claude 5.5 generation is the default, and Opus is the default for most paying users.
- The local machine can act as an attested remote tool host.
- Bash safety lost its LLM layer and gained deterministic and server-side checks.

The counting method had to change with the packaging, so every headline delta here is quoted against a
same-method recount. The counts roughly double even on that basis. Two things did **not** move: the
Datadog client token (still `pubea5604…`, **not rotated** across two comparisons now) and the bigger
privacy posture (no hardware fingerprint over the wire; 1P telemetry off on every 3P plane unless
`CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST` is set).

**For anyone tracking this:**
- The device keypair **survives logout**. Remove `~/.claude/.device-keys.json` by hand if that matters.
- The `<total_tokens>` countdown is now **on by default**, and so is defaulting into auto mode where
  permissions allow it.
- The GrowthBook kill switch for bypass mode is gone. *Tentative:* only the managed setting
  `disableBypassPermissionsMode` can disable it now.
