# 遥测、订阅与账号状态

## 遥测管线

2.1.300 的主管线是 `https://api.anthropic.com/api/event_logging/v2/batch`。事件在 sink 建立前可进入
1,000 项队列，满时丢弃最旧项。GrowthBook 负责远程功能值与 exposure 事件；Datadog、OpenTelemetry 和 plugin telemetry
是附加路径，受配置、provider plane、隐私开关与采样影响。

核心元数据可包含 `device_id`、`account_uuid`、`organization_uuid`、`session_id`、
`platform`、`client_type`、`entrypoint`、`appVersion`、`subscriptionType` 与 `rateLimitTier`。

## 订阅与账龄

Profile 对象包含 `accountCreatedAt`、`subscriptionCreatedAt`、`subscriptionType`、`rateLimitTier`。
限额 reset/offer 格式还包含：

- `tenure_bucket`: `under_14`、`14-29`、`30-89`、`90-364`、`365+`。
- `billing_path`: `stripe`、`apple`、`google_play`、`other`。
- `billing_period` 与 `extra_usage_state`。

这证明账龄和计费路径会被服务端用于部分产品资格规则，但不能由此推导它们也是封禁打分项。

## 账号状态

`account_on_hold` 是客户端明确识别的 API/OAuth 错误。它会导致：

- OAuth refresh 被识别为 hold，并产生对应健康事件。
- API 层将账号标记为 blocked，终止正常使用。
- 终端展示 hold 信息，并引导用户访问 `https://claude.ai/restricted` 查看或申诉。

`verification_required`、`billing_error`、`organization_on_hold`、`organization_disabled`、
`refused_ip_allowlist` 是不同的结果类型。它们的存在能证明服务端有账号、计费、组织和网络策略裁决，
但不能证明这些裁决共享一个对外可见的“信任分”。
