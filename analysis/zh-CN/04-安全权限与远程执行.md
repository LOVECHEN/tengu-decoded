# 安全、权限与远程执行

## Bash 与权限检测

2.1.300 已移除早期的 Haiku Bash 前缀分类器，改用确定性前缀提取和破坏性命令规则。
模型分类仍用于另一条 auto-mode 权限路径。有效的执行边界由本地规则、permission mode、
sandbox、工具 schema、功能开关和服务端策略共同决定。

## Sandbox 与远程面

语料包含 Linux bubblewrap、macOS seatbelt 与 Windows WFP 等平台后端，同时包含远程会话、bridge、worker、
self-hosted runner 和设备绑定表面。远程 bridge 会上报持久 machine ID，worker heartbeat 还可包含间隔和 idle 时间。

## 与账号风控的边界

执行安全和账号风控是两套不同的问题：

- 命令危险性分类、sandbox 和 permission 决定“当前会话能不能执行操作”。
- `account_on_hold` 和组织策略决定“当前身份能不能继续使用服务”。
- 设备、会话和遥测为服务端提供可观测信号，但其风控权重与裁决函数不在客户端。

因此，不应把本地命令安全规则、GrowthBook 功能标志和账号 hold 结果合并解读为单一“积分引擎”。
