# 身份、设备与外发链

## 持久标识

| 标识 | 生成 | 生命周期 | 外发方式 |
|---|---|---|---|
| `userID` | `randomBytes(32)` 的 64 位十六进制字符串 | 按安装持久化，退出登录后仍保留 | Messages API `metadata.user_id.device_id`、一方事件、GrowthBook、OTel、plugin telemetry 原样外发 |
| `machineID` | `randomBytes(32)` | 按安装持久化 | 仅见于错误数据的 12 字符截断值 |
| `summonSidKey` | `randomBytes(32)` | 按安装持久化 | 密钥本身不外发；只外发 `HMAC-SHA256(key, sessionId+slug)[:16]` |
| `remoteControlMachineId` | `randomUUID()` | 按安装持久化 | 作为 `machine_id` 原样发送至 `POST /v1/environments/bridge` |
| 设备密钥 | 每账号 ECDSA P-256 keypair | 退出登录后也会恢复 | 注册公钥，会话绑定时提交签名证明 |

这些值是随机安装标识，不是由硬件序列号派生的传统硬件指纹。但它们能稳定地关联安装、账号、
组织和会话，所以在服务端仍然具有设备识别价值。

## 主要关联键

- Messages API metadata：`device_id`、`account_uuid`、`session_id`、`parent_session_id`。
- GrowthBook 属性：设备 ID、account/org UUID、organization role、subscription type、rate-limit tier、subscription creation time、entrypoint、app version。
- GrowthBook exposure：`experiment_id`、`variation_id`、`device_id?`、`account_uuid?`、`organization_uuid?`、`session_id?`。
- 一方事件：`user_id`、`auth.account_uuid`、`auth.organization_uuid`、`session_id` 和核心元数据。
- Remote bridge：远程控制 machine ID、会话 ID、worker epoch、heartbeat 和 idle 信息。

## 对风控判定的含义

设备数、多设备登录、并行会话、远程会话和登录刷新行为，在数据模型上都是可观测的。
但客户端只实现“生成、保存、上报和绑定”，没有实现“多一台设备扣多少分”之类的裁决。
